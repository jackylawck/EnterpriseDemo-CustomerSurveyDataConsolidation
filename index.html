本系統為雙軌架構（純前端網頁版 + 本機 Python 桌面版）之開源企業示範，專為解決 Microsoft Forms 原始橫向表格難以閱讀與人工統計易出錯之痛點而設計，能瞬間完成矩陣轉置、分組平均與低分標紅。 This open-source dual-mode (Client-side Web + Offline Python CLI) enterprise demo eliminates manual spreadsheet formatting errors by transforming raw horizontal Microsoft Forms exports into transposed executive matrices with live formulas and conditional alerts.

操作步驟 Quick Steps

  1. 點擊「一鍵載入虛擬數據體驗」即時測試，或拖曳您的問卷 RAW `.xlsx` 檔案。 Click "Load Synthetic Demo Data" for an instant walkthrough, or drop your own RAW `.xlsx`.
  2. 引擎會自動校驗必要欄位、依字典歸戶客戶集團，並於頁面顯示 KPI 與低分警示。 The engine validates required columns, normalizes client groups, and renders KPIs & alerts.
  3. 利用分類標籤檢視特定範疇或文字意見，再點擊「下載完整整合報表 (.xlsx)」取得帶公式活頁簿。 Filter by category or comments, then click "Download Consolidated Report (.xlsx)" for the formula-driven workbook.

確定性計算規則 Deterministic Calculation Rules

  • 低分紅字預警：任何單項評分嚴格小於 7 分（< 7），自動套用粗體紅色字體（#FF0000）。 Low-Score Alert: Any rating strictly below 7 (< 7) is styled in bold red (#FF0000).
  • 動態分母百分比：各代表獨立平均分按實際有效作答題數（validCount × 10）計算，避免不適用題目拉低分數。 Dynamic Denominator: Individual percentages divide by actual answered items (validCount × 10) to avoid N/A penalties.
  • 多層動態公式：Excel 內建原生 `SUM()` 與 `AVERAGE()` 公式，後續於本機微調數值時會自動重算。 Native Excel Formulas: Embeds live `SUM()` and `AVERAGE()` formulas for seamless post-export adjustments.
